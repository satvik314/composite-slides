# composite-slides
Multi-theme presentations in simple HTML

A **composite deck** gives every slide its own visual language — palette, typography, ambient motion, cursor, sound, and exit transition all derived from that slide's content — while a shared skeleton keeps it feeling like one presentation.

## Decks

- [`city_slides_composite.html`](city_slides_composite.html) — **The Acre Atlas**: how big are the world's cities? Nine cities, nine visual dialects (taxi-grid NYC, neon Tokyo, monsoon Mumbai…).
- [`interface_ages_composite.html`](interface_ages_composite.html) — **The Interface Ages**: fifty years of UI design, where each slide is rendered in the design language of its era (terminal green → Geocities → gloss → flat → dark mode → AI chat).
